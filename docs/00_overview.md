## Overview

## 한 줄 요약
로컬 사진 폴더를 **문장으로 검색**할 수  있게 만드는 개인용 검색 시스템

## 배경
사진이 많을수록 "어디에 저장헀는지" 기억이 흐려지고 폴더/파일명 검색 기반 시스템은 한계가 생김
특히 "작년 겨울 눈이 많이 오던 공항", "야간 캠핑"처럼 **떠오르는 기억**은 키워드로 정확히 표현하기 힘듬

## 사용자 시나리오 (User Stories)
- 사용자는 "바닷가에서 우산쓰고 있던 날" 같은 문장으로 사진을 기억한다
- 사용자는 사진을 외부 서버로 올리고 싶지 않다(개인정보)
- 사용자는 유사한 기억(사진) 또한 제공받고 싶다
1. 사용자의 컴퓨터에 저장해놓은 사진들을 관리, 검색한다.
2. 사진이 저장된 폴더를 사용자가 지정한다.
3. 사진 삭제, 이름변경, 새로운 사진을 특정하여 인덱싱을 관리한다.
=> 폴더 선택 -> Library 등록 -> Library 상태 확인 -> 필요에 따라 분석/인덱싱

## 프로젝트 목표
1) 사진 검색의 용이함
2) 효과적인 라벨링 방식(자동 + 최소한의 수동) 설계
3) 희미한 기억으로도 유사한 사진을 찾아서 제공
